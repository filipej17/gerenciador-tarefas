# Gerenciador de Tarefas

Projeto simples de lista de tarefas em HTML, CSS e JavaScript.

## Funcionalidades
- adicionar tarefas
- marcar como concluída
- remover tarefas
- salvar no navegador

## Como abrir
Abra o arquivo `atividade.html` no navegador ou use o Live Server no VS Code.

## Tecnologias
- HTML
- CSS
- JavaScript
